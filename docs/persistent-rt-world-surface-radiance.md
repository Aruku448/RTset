# 持久 RT 世界：表面与方向辐射第一版

## 与初版光栅探针路径的区别

初版用深度太阳阴影图、白色太阳和漫反射探针完成显示，缺少 RT 遮挡与材质高光。本版保留高频几何可见性绘制，但移除运行路径中的太阳深度图；光照数据由低频 RT 生成并保存，显示只读取缓存并解析当前观察方向。

这实现了“相机转动不重新求解光路”的第一阶段。每帧仍需要可见性、投影、材质响应与图像合成。没有宣称零绘制、异步世界更新或稳定 240 FPS。

## 数据与工作合同

### 表面太阳辐射

- `WorldSurfaceRadiance` 保存静态与实体三角形角点的入射太阳光，按 GPU 绘制顺序索引，不把材质索引误用作角点索引。
- 角点射线起点向三角形内部收缩 2%，再沿面法线向采样光源偏移 0.002 方块；太阳方向使用原完整 RT 的有限圆盘 Sobol 采样。
- 原 RT shadow any-hit/miss 链路处理草木裁剪、玻璃/水 RGB 透射和实体遮挡。太阳颜色来自同一介质的太阳透射或原温度颜色，并包含强度、天气与阴影强度。
- 同一个光源样本分别计算 static/full visibility。静态源辐射平均保存在 RGB32，实体增量 full-static 独立用 RGB16 保存，避免动态遮挡被揉进静态 64 次平均。
- 实体准入/布局改变使旧实体增量失效；姿态变化在世界时钟上重新追踪，不以每个显示帧清空静态场。实体角点每个世界更新刷新；静态角点按预算轮转。
- 发布/训练银行独立，GPU 复制完成后才训练；显示读取上一份发布银行。transfer 写入重叠处有明确的写后写屏障。下一显示帧在上一提交 fence 完成后切换银行。
- 当前每三角形三个角点，片元按重心坐标插值。未训练直接光为零；环境近似仅用于未成熟 GI，不伪造无遮挡太阳，也不在显示补射线。

### 方向辐射与材质

- 世界探针在原九个 L2 SH 系数之外增加 8×8 八面体方向桶，各桶保存原始入射 Li 和样本数。
- SH 的 cosine convolution 求 diffuse irradiance E；方向查询求入射 Li。两者不是同一数据，反射查询不重复乘 albedo 或 π。
- 显示以当前法线与观察方向计算 Schlick Fresnel、GGX NDF 和 Smith visibility，解析太阳高光（采用中心光源与太阳半径控制的最小宽度近似）；金属 F0 来自反照率，漫反射能量按 Fresnel 和金属度分配。
- 间接反射按当前反射方向读取缓存 Li。粗糙表面使用 SH 频带衰减，较光滑表面混合成熟方向桶。这是低分辨率预滤波近似，不是完整 GGX 环境积分或精确镜面光路。
- diffuse E 与 reflected Li 共用一次八角点空间 gather，复用可见性、系数与置信度；SH 基与粗糙度频带仅求一次。

### 调度与实体

- `worldRasterDisplayEnabled` 保留原配置键，F9 文案改为“持久 RT 世界（实验）”。
- `persistentRtUpdateIntervalMs` 默认 50 ms，仍是同 GPU 队列世界时钟。
- `worldSurfaceTrainingBudget` 默认 65536，最大 131072，表示每次静态角点数；实体角点额外刷新。0 冻结表面训练。
- `worldProbeTrainingBudget` 保留原值（默认 1024），控制方向/间接路径预算。
- 动态 RT BLAS/TLAS 只在世界更新帧更新，实体显示快照高频更新。原生手持物保持独立显示。
- 日志增加 `world_surface_samples`；`world_trace_calls` 统计探针和表面两个世界 dispatch。普通显示 `display_trace_calls=0`，不进入 NRD。

## 当前画质、时延与性能限制

1. 角点插值不能表达一个三角形内任意细的阴影边缘；方向桶与空间网格不能提供无误差镜面反射、薄墙可见性或表面附着缓存。探针尚无内部重定位。
2. 静态太阳图更新完成一轮需约 `staticCorners / budget × interval`。移动实体投到静态表面的增量也受这个轮转延迟影响；其新增/移除需要重新训练相关角点。当前没有局部遮挡影响范围的优先队列。
3. 太阳/月亮、天气和介质变化通过世界工作器持续更新，保留已发布观察值；不再改变 storage generation 或清空场。低预算下源变化响应仍受轮转与运行平均的时间常数限制，不能把保留旧观察等同于光照已经更新完成。
4. 天空背景目前仍是清屏色；月光直接层、相机段大气、体积光、透明可见性/折射和完整 PBR 细节法线尚未恢复。静态自发光通过探针传播；动态/手持发光尚无独立缓存。草木特殊受光曲线也尚未共享。
5. 本版不调用光栅太阳阴影图，旧 `WorldRasterSunShadow` 保留为历史实验/测试参考。缓存 RGB 透射不等于透明表面的显示已完整实现。
6. 额外表面双银行约 192 字节/三角形，加上合并训练位置约 48 字节/三角形及实体预留。方向探针行从 64 扩为 320 words，双银行约 2560 字节/探针。大场景显存与银行复制需实机监测。
7. 世界更新和显示仍串行同队列。静态几何暂未做专门显示剔除，实体仍上传变换后的顶点。更新帧耗时可能超过 4.17 ms，不能承诺稳定 240 Hz。

## 验证

- `./gradlew check jar --offline`：66 个任务通过，包含完整 RT 两种大气变体、显示 shader、ABI 与投影/调度测试。
- `WorldSurfaceRadianceTest` 导出生产缓存函数 GPU fixture：发布银行隔离、角点重心插值、遮挡、采样序号、NaN 拒绝、边界/代数失效、实体任务优先与 signed delta 失效。
- `WorldIrradianceFieldTest` 导出生产函数 GPU fixture：原 SH/TTL/可见性合同，以及相反方向不同 Li、Li 与 E 的 π 关系、合并 gather 的能量一致性。
- 两组实际 Vulkan compute 回读各 12 项、0 差异。
- `gpu_world_raster_smoke.c` 实际执行生产 vertex/fragment：alpha/depth/MRT、非零 jitter 静止运动、图像 Y、缓存太阳遮挡、RGB 透射、金属 GGX、移动/转动相机读取同一缓存。
- 图形 fixture 的输入辐射是可控制的种子；它不替代完整 Minecraft 世界中的 RT 建树、阴影射线和画面验证。未测游戏整帧 FPS。

## 2026-10-05：加载期间保留缓存

修复了三类信息丢失：光源参数使 generation 反复变化、区块发布使顶点布局重建、静态探针超时被拒绝读取。

- storage generation 现在在本渲染资源生命周期内稳定；相机和天空参数不触发整体清空。
- `WorldCacheMigration` 按 Section key、顶点/材质内容匹配表面记录。区块重排及场景相对原点变化不影响观察值；修改的区块接收新空记录，其余记录 GPU 复制到新布局的两个银行。
- 探针间距由配置中的场景半径决定，使用至少 16 方块的二次幂间距，不随已加载区块数量变化。覆盖范围足够时保持旧网格；扩展/平移时按相同绝对世界坐标迁移重叠探针。
- `maxAgeMs=0` 表示持久观察，不因训练暂停或经过 30 秒而消失；其他正值仍保留原过期语义。
- 迁移按“先初始化目标，再复制旧发布银行，再训练未发布银行”记录；旧 GPU 缓冲在迁移提交后的下一次 fence 等待完成后释放，避免在队列使用期间销毁。
- 这仍是预算式低频训练。静态场收敛后自动休眠、方块修改影响范围优先调度、改动区块内部的逐三角形迁移尚未实现。方块变化对其他区块的阴影/GI 影响通过后续轮转更新，期间可能暂留旧照明。
- 移出当前网格/场景的区域仍会被回收，尚无跨卸载区块持久存储。移动到已卸载区域后返回不保证零重建。
- 扩展迁移会短暂保留旧、新缓冲，增加峰值显存；不是整场景缓存的零成本扩容。

验证：`WorldCacheMigrationTest` 覆盖未变化区块的加载/重排、方块编辑、原点平移以及 1859 组网格重叠；原生产 GLSL 的 GPU 过期用例修复前 output 9 失败，修复后 RX 7800 XT 的 12 个输出全部一致。`check jar` 通过。尚未验证 Minecraft 实际运行中的加载过程、画质或帧率。
