# 实体阴影与 NRD 照明分离

## 问题

旧合成在发现实体遮挡标记时返回整个原始像素，因此该像素的静态光源照明也绕过 NRD。另一个缺口是：直接光 NEE 有贡献，但 BSDF 延续没有有效距离时，该分量回退到当前帧噪声。

## 实现

- 对检测到动态实例遮挡的太阳、月光、天空、面积灯和局部体积光样本，追加一次忽略动态实例的静态可见性查询。没有动态遮挡或关闭 NRD 时不追加查询。
- 静态基线进入 diffuse/specular NRD 通道。实际照明减去静态基线的有符号 RGB 差值写入现有 DirectDiffuse AOV，在降噪后加回。差值保持负值直到最终合成。
- 主表面及后续反弹的直接光遮挡均进行差值分离；动态实例边界也包含现有动态方块实体。
- 保留静态透明材质的 RGB 透射。阴影 payload 的透射、动态遮挡标记、忽略动态实例开关合并到同一 location 1 结构，保证一次 traceRayEXT 能传回全部状态。
- 有直接光但没有有效延续距离时，使用面积灯距离或现有方向光环境距离哨兵，避免有效光照因距离为零而跳过降噪。

## 边界

实体阴影差值按要求不经过 NRD，其随机软阴影采样噪声仍可能可见。追加静态查询有额外开销，限于检测到动态遮挡的样本。该分离只针对光源可见性的实体遮挡，不移除实体表面的照明降噪，也不移除路径中实体材质参与的反射。

直接可见的自发光与天空背景仍使用原有独立路径。太阳/月光的有限段大气散射仍不属于表面 NRD 信号。局部体积光使用现有表面重投影近似，并非独立体积历史。

## 验证

通过 rayTracingShaderContractTest、rayTracingAtmosphereShaderTest、nrdCompositeContractTest、nrdMotionContractTest 和 jar 构建；包括实际 raygen 两种变体、阴影阶段、NRD 合成着色器编译，以及强度零时差值分离与重组的能量恒等式检查。这些是编译与 CPU 合约验证，尚未完成 GPU 画面验证。
