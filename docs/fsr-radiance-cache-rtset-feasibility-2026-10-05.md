# FSR Radiance Cache 与 RTset 接入评估

日期：2026-10-05。范围：只核查可行性，没有修改运行代码、配置或部署 mod。

## 结论

**算法可以借鉴，当前官方组件无法直接接入这套 Linux/Vulkan/RX 7800 XT 的 RTset。** 公开 RC 组件提供 DX12 DLL 和接口头，没有可用的 Vulkan 后端或公开训练/推理 shader；官方支持表要求 RX 9000 系列或更新。详细官方证据见 [支持核查](fsr-radiance-cache-official-support-2026-10-05.md)。固定 SDK commit：`60f4ea81909200d8542eca14dccb2628b763a9a3`。

现有 FSR 3 不构成接入基础：`RtestFsr3Upscaler.java:54–60` 明确只实现八个 Vulkan 上采样 compute pass，没有 FidelityFX 原生后端。加入 RC 头文件或 JNI 入口，不能使 DX12 组件接受 Vulkan 资源。将整条渲染路径迁到 DX12 是另一项工程，不是替换上采样库即可完成。

## 算法与本地路径的匹配

RC 是在线训练的路径尾部辐射估计器，可减少后续间接光追踪。它不是 NRD 替代品。训练、推理自身也消耗 GPU 时间，RTset 当前最多四次 GI 反弹，因此必须实测收益。

| 本地条件 | 检查结果与需要处理的内容 |
| --- | --- |
| 迭代路径追踪 | `RayTracingShaderRaygen.java:1460` 附近保存 throughput/MIS 状态，适合在后续散射点提出查询，但没有逐顶点训练目标与逆向累积记录。 |
| 采样与能量 | `:2023–2110` 按首跳 BSDF 分配 diffuse/specular，并保留 RR、介质及光谱权重。缓存替代的必须是明确的剩余路径贡献，不能把已经计入的 NEE、发光或天空再次相加。 |
| 工作色域 | FSR 输入是线性 Rec.2020 HDR。训练目标和查询结果应沿用这套线性色域；不能使用显示变换后颜色。 |
| NRD | `:2530–2564` 汇总两路照明 AOV；缓存贡献要在 NRD 输入形成前写入相应通道，继续由现有 motion pass 做解调和 hit distance 转换。 |
| 实体阴影 | 当前把 signed dynamic shadow delta 从 NRD 输入扣除、在合成后加回。若训练目标已混入实体遮挡，缓存会记住并平滑该遮挡；不能仅靠现有 delta 扣除消除缓存中未知的历史误差。 |
| 世界坐标 | `RayTracingVulkanPass.java:2227–2231,2685–2687` 使用 geometry origin 相对坐标。模型输入需稳定的空间映射；移动 origin 或包围盒时直接重新归一化会改变输入语义。 |
| 调度 | `RayTracingVulkanPass.java:3486–3488` 当前 trace 后立即进入后处理，需要插入查询/训练、结果重建及相应 Vulkan 依赖。 |

## 若实现自有 Vulkan 缓存，建议的最小范围

这是依据本地代码提出的工程路线，**不等于移植 AMD 的神经网络实现，也不保证相同画质或性能**。

1. 首先只缓存不透明漫反射间接光的路径尾部，保留直接 NEE、RGB 透明阴影、发光表面、镜面/折射、水介质和体积积分的原有路径。保留首跳采样，以免直接用低频缓存替代接触细节。
2. 初期缓存目标采用静态几何遮挡；实体影响区域或未能证明动态修正完整的路径继续完整追踪。测试实体移动后的残影及照明泄漏。
3. 逐顶点记录独立的局部贡献和散射权重，再逆向构造训练/更新目标；不要以整条相机路径最终像素颜色作为每个顶点的目标。明确 BSDF/反照率因子化合同，避免重复乘反照率。
4. 采用稳定空间锚点，按区域失效；传送、维度、材质包更换需重置或回退。普通区块发布不应每次清空全部缓存。
5. 查询未命中、冷启动或失效时完整追踪。先证明接入后的 NRD AOV 与原路径能量分类一致，再增加其他材质范围。

Vulkan 空间哈希辐射缓存是可以独立实现的候选；若坚持在线神经网络，则需自有训练/推理 Vulkan 实现及相应硬件能力验证，公开 SDK 没有提供这部分可移植源码。

## 性能验收

前一轮日志中 RT pass 约 36–42 ms，但它混合主射线、直接光阴影、间接光和体积贡献，不能全部算成缓存可节省时间。构建/上传/TLAS、直接光及体积开销也不会由缓存自动消除。

必须在固定视角和设置下计时：原路径、短路径、查询、训练/更新、合成、NRD、全帧；报告冷启动和稳定期，记录缓存显存与失效率。画质至少覆盖日夜变化、实体移动、区块加载、室内外转向、传送和高亮发光材质。净收益条件为“省下的路径追踪时间 > 查询 + 更新 + 合成 + 新同步成本”，当前没有足够数据承诺 FPS 提升。
