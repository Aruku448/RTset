# 半透明天空盒与物理大气混合

当前按用户最新要求，默认开启 `skyboxDaylightOpacityEnabled`，使用**两个独立控制点表**，不再是统一0.15→0.90函数。

- 黎明至中午（亮度→不透明度）：0→15%、1→10%、2→8%、6→13%、8→20%、9→35%、10→60%、11→70%、15→90%。
- 中午后：15→90%、13→70%、10→40%、2→30%、1→20%、0→15%。未单独提供的下午15端点沿用90%，保证晴天中午连接一致。

每两个控制点之间使用半余弦权重 `(1-cos(pi*t))/2` 插值，精确经过所有给定点，无过冲，段端斜率为0；黎明0至2亮度不透明度先下降，不能再强制整条曲线单调递增或最低15%。整个表的最低是黎明8%，黑夜仍15%。亮度直接使用原先的浮点昼光0–15。

分支按真实游戏世界时钟：6000（中午）至18000（午夜）采用下午表，其余采用黎明/上午表。采用时间分支而非逐帧亮度导数，避免雨天亮度抖动在两表间反复跳转。晴天中午15亮度两表90%，夜间0亮度两表15%；若自定义天气/维度使中午亮度不足15，两表可能存在切换差值，目前不擅自添加跨表blend而偏离指定控制点。

背景及反射/折射共用，太阳直射不变。关闭自动曲线才使用手动值；每日正常变化不逐帧重置历史，手动值或曲线模式切换才请求reset。

亮度使用MC26.2 `EnvironmentAttributes.SKY_LIGHT_LEVEL`的浮点dimension值，不用玩家所在位置的遮挡光，也不用整数`getSkyDarken`。原版`timeline/day`白天15、夜间4，先用`clamp((skyLightLevel-4)/11,0,1)*15`映射为用户定义的昼光0–15；天气/维度属性生效。夜间基线保持最低15%。不按真实时间或已偏移的RT太阳方位猜亮度。该属性仍以真实游戏时钟为准：离线渲染独立锁定时钟不会自动覆写该属性，需后续专门适配。

原手动混合：保留天空盒，新增 `skyboxTextureOpacity`（0–1，默认0.25），`skyboxTextureEnabled`新配置默认true。已有配置中的false不强制覆写；F9可打开「旧天空盒贴图」。同时开启Prime物理大气即可设置「天空盒不透明度」。0为纯物理天空，1为纯PNG，0.25为25%PNG+75%物理天空。

这是艺术背景的线性alpha-over，而不是给Vulkan背景attachment写透明alpha，后者不会正确混合出大气。PNG先sRGB解码并转Rec.2020；物理LUT保持原线性空间；共享miss路径用mix混合，背景、反射和折射一致。既有PNG昼夜/色温/天气处理保留，太阳盘在混合后独立加入，surface太阳NEE与有限段雾不按天空盒比例衰减。PNG自身若画了太阳仍可能存在贴图太阳与真实太阳并存；没有借blur或修改贴图隐藏。

未开启物理大气或初始化fallback时，保持原完整PNG回退；opacity在该路径不生效，避免透明贴图退化为黑色。关闭天空盒开关时不采样PNG，但物理天空、太阳和体积光保留。物理求解的medium参数不因艺术混合改变；混合背景不是严格能量一致的纯物理环境。

`RayTracingVulkanPass`在原16-byte atmosphere UBO闲置lane4上传opacity，不改变304-byte camera ABI及descriptor数量。改变opacity请求NRD/FSR历史reset，稳定参数不反复reset。没有增添纹理、渲染附件或新GPU同步路径，物理路径新增至多一次原skybox采样（opacity=0或开关关闭时跳过）。

验证：`./gradlew test jar correspondingSource --offline`60tasks通过；实际legacy/physical RayGen和query共四variant通过Vulkan1.2 SPIR-V校验。新增source contract覆盖线性色彩混合、在太阳盘前混合、spare lane上传和历史reset；数值测试逐个验证两表全部控制点、每段单调方向和无过冲、半余弦中点、上下界/非有限输入、天空光归一化及时间分支（含负/跨日时钟）。源码/编译测试不证明实机视觉效果或性能。未部署、未修改实例配置、未启动游戏。原天空盒关闭诊断部署文档保留为历史记录。
