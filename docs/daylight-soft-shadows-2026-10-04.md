# 太阳软阴影与日照强度调整

## 发现

太阳 NEE 原本已采样有限圆盘，但角半径写死为 0.00471 rad（约 0.27°），主表面每帧仅一次阴影查询。近处半影很窄，单次采样的瞬时结果仍然是遮挡或透射，NRD 关闭时尤其容易呈现硬边。太阳强度的配置与 UI 上限都为 2，输出曝光固定为 1，大气消光仍会进一步衰减日照；不能据此把消光本身判定为错误。

## 实现

- `sunAngularRadiusDegrees`：0.05–5°，默认 0.27°。通过 Camera.forward.w 上传弧度，不改变 304 字节 UBO。
- `sunShadowSamples`：1–16，默认 4。Camera.right.w 上传；主表面按等立体角面积分层采样太阳圆盘，次表面保持 1 次。
- 每条射线分别评价 RGB 可见性、大气透射、BRDF 与余弦，然后平均辐射贡献。保留透明阴影和动态遮挡信息。
- 可见太阳圆盘、圆盘采样与方向 PDF 使用同一角半径；总辐照度按立体角归一化。小角度的立体角使用 4π sin²(radius/2) 避免 float 的 1−cos 消减误差。
- 多样本 NEE 与 BSDF 天空中的太阳命中使用匹配的样本数 MIS 权重；最后一次表面没有延续时 NEE 权重为 1。
- `sunIntensity` 的配置和 UI 范围扩大至 0–16，保持太阳直射、物理天空和太阳体积散射共用光源强度。
- 角半径、采样数与强度变化触发历史重置。
- 补齐上一轮天空光 NEE 的镜面贡献到 NRD 镜面 AOV，避免开启 NRD 时丢失该能量。

## 验证与部署

执行 `./gradlew rayTracingShaderContractTest rayTracingAtmosphereShaderTest jar --offline`，成功。shaderc 编译实际 raygen 的物理与传统两种变体及活动阶段；已有光照/能量/信号合约同步多样本累加与天空 AOV 后通过。未做 GPU 画面对比或帧率测试。

用户确认关闭客户端，进程状态也确认退出后部署。实例参数设为太阳强度 6、角半径 1°、主表面采样 8；其他配置值保持原样。这是用于观察效果的艺术参数，并非真实太阳辐照单位。太阳强度会同时增加物理天空和雾散射；较大的光源角半径会增大可见太阳盘。

主表面最多增加 7 次太阳阴影查询，确切开销需在游戏内测量。接触阴影仍然清晰，较远遮挡形成更宽半影。本次针对太阳表面阴影；体积太阳阴影仍沿中心方向积分，月光/发光体的采样规则保持现状。
